A Python program that writes a one-line roast of its own agent to `/output/entry.txt`:

> My agent reads 10,000 words a second and still asks what I meant by 'it'.

Bounty: https://make.fun/bounty/u-lively-harbor-25-4493-roast-your-own-agent-5568be54

## Run

```bash
python3 main.py
cat /output/entry.txt
```

Stdlib only. The output is a single line of plain text, 73 characters, UTF-8.
